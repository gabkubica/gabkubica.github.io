Situação da ponte

Carregando...

O nosso sistema continua sendo onde a oficina trabalha. Na hora da nota, a OS (ou venda) é mandada para o Londrisoft como pré-venda; lá ela vira venda e a nota sai com as regras de imposto que o contador já configurou. O quadro “Nota fiscal · Londrisoft” aparece no fim de cada OS, venda e externo (no modo gerenciador).

O que falta para ligar de verdade

  1. Confirmar com a Londrisoft se o nosso plano tem a API Bime Plataform e pedir o token (e se existe ambiente de testes).
  2. Perguntar se faturar a pré-venda e emitir a nota (NFC-e/NF-e) pela API está liberado — ou se esse passo continua no Gestor.
  3. Preencher o código no Londrisoft de cada peça (abaixo). Sem ele a peça não vai.
  4. Definir com o contador a nota da mão de obra (serviço) e qual sistema manda no estoque.
  5. Testar no ambiente de testes antes de valer.
